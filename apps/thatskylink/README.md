# thatskylink

A link redirector for Sky: Children of the Light. So magical!

This is intended for everything related to Sky.

## Redirects

Read this like `https://thatsky.link/<Identifier>`.

For example, https://thatsky.link/wiki will take you to https://sky-children-of-the-light.fandom.com.

Every identifier is listed on the [website](https://thatskyapplication.com/thatskylink).
